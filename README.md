# nyxragon.in

Personal site — security research, writeups, talks, and work.

Built with **Next.js** (static export) on **GitHub Pages** at [nyxragon.in](https://nyxragon.in).

## Quick start

```bash
npm install
npm run dev
```

## Write a post

```bash
npm run new:writeup -- my-post-slug
```

See **[CONTENT.md](CONTENT.md)** for where to edit everything.

## Pages

| Page | URL |
|------|-----|

| Experience | `/experience/` |
| Writeups | `/writeups/` |
